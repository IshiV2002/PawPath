STAFF ACTION GUIDANCE

Data & Preprocessing Notes

    Notice: This model predicts admission duration (> 30 days) from intake data, regardless of outcome type (adoption, return to owner, or transfer). Staff must make all animal care and welfare decisions.

    ♡
    Made for shelter teams

    Based on Sonoma County, California, USA data. This is a student prototype, not a deployed shelter tool.

    📊 Model Architecture & Methodology ⌄

    Algorithm: Tuned Random Forest (400 trees, min_samples_leaf=1, max_features=0.5, unlimited depth)

    Features: 183 encoded intake features plus 8 age interactions

    Training / validation / test: 6,096 / 1,163 / 1,672 admissions; stratified 3-fold cross-validation on training data

    Target Variable: long_stay_30 (stay > 30 days)

    Decision Cutoff: 0.3758, selected to maximize positive-class F1 on validation data

    Held-out test results: 73.3% accuracy, 56.9% balanced accuracy, 30.6% long-stay recall. The majority-class baseline had 81.2% accuracy and 0% long-stay recall.

    Data Leakage Prevention: Only intake-known attributes used. Post-intake dates, disposition, and duration are strictly excluded.
